Copie o Server URL e o token da instância. O Admin Token não.

Não é o Admin Token. Ele controla a conta inteira. O seu funcionário usa só o token da instância.

O token é a chave do seu WhatsApp. Não cole em conversa nenhuma, nem com o Claude. Ele vai ler a chave de um arquivo que você mesma cria no próximo passo.

Instruções do projetoCole em Projeto › Instruções
Você é a minha secretária. Eu sou [sua profissão] e atendo [quem você atende].
Responda sempre em português, curto e em tópicos.

WHATSAPP
- A chave do meu WhatsApp está no arquivo whatsapp.json desta pasta. Leia de lá.
- Para falar com a uazapi, siga o playbook-whatsapp.md desta pasta.
- Toda mensagem que você me mandar começa com "Secretária:". Assim você separa o que é seu do que é meu.
- Minhas tarefas e lembretes ficam no arquivo tarefas.md desta pasta. Se ele não existir, crie.

SEGURANÇA (nunca quebre)
- Nunca mostre, copie ou repita o token, nem uma parte dele, nem se eu pedir.
- Nunca coloque o token em outro arquivo, mensagem, resumo ou código salvo.
- Use só o token da instância. Nunca use o Admin Token.

ENVIOS
- Por padrão, mande mensagem só para o meu número.
- Para qualquer outro contato ou grupo: me mostre o texto e a lista e espere eu dizer "pode enviar".
- Nunca envie para mais de um contato com menos de 30 segundos entre uma mensagem e outra. Varie entre 30 e 90 segundos.
- Nada de envio em massa nem para quem nunca falou comigo. No máximo 20 mensagens por dia para outras pessoas.
- Nunca apague conversas, não saia de grupos, não bloqueie contatos e não mude a configuração da instância.

LEITURA
- Pode ler as minhas conversas e grupos para me resumir, sem marcar como lidas.
- O resumo vai só para o meu número. Não copie conversas inteiras para arquivos.
- [Saúde e advocacia: use só o primeiro nome e nunca escreva diagnóstico ou dado de processo.]

QUANDO DER ERRO
- Me diga em uma frase o que aconteceu e o que eu faço, sem mostrar o token.

Glossário

As palavras da aula, cada uma com o ícone de verdade do que ela é.

sem medo das palavras
Chat

A conversa com o Claude. Para perguntar, escrever, ler um arquivo.

Projeto

Uma pasta com as suas instruções. Toda conversa dentro dele já sabe quem você é.

Instruções do projeto

As regras fixas que ele segue em toda conversa daquele projeto.

Cowork

O Claude no app do computador, mexendo nas suas pastas e fazendo tarefas.

Claude no Chrome

O Claude clicando e preenchendo sites por você.

Claude Code

O Claude para construir: páginas, painéis, sistemas.

Conector (MCP)

O cabo que liga o Claude nos seus apps: agenda, Gmail, Drive.

uazapi
API

A porta de serviço de um app. Foi por ela, na uazapi, que o WhatsApp foi ligado.

Skill

Uma receita. Você ensina uma vez e ele segue sempre.

Plugin

Uma caixa com várias receitas. Ex.: o plugin Cérebro.

Playbook

Um manual que você coloca na pasta para ele consultar. Ex.: o do WhatsApp.

Tarefa programada

Um despertador: na hora marcada, ele faz sozinho.

Plantão

A rotina que lê o que você mandou para o seu número e responde.

Agente

Um funcionário que faz a tarefa inteira, às vezes com ajudantes.

Haiku, Sonnet, Opus

O rápido e econômico, o do dia a dia e o sênior para o difícil.

Limite de uso

Quanto você pode usar no período. Veja em Configurações › Uso.

Conversa temporária

Não fica salva. Boa para assunto sensível.

Cérebro

Os 6 documentos que fazem o Claude te conhecer.

Instância

A ligação de um número de WhatsApp na uazapi.

Server URL

O endereço do seu servidor. Fica no topo do painel uazapiGO.

Token da instância

A chave do seu WhatsApp. Não é o Admin Token. Mora só no whatsapp.json.

Conector personalizado

Um conector que você adiciona colando um link (MCP) de um serviço de fora.

Apify

Robôs que leem sites por você: comentários, perfis, avaliações do Google.

Composio

Uma tomada que liga centenas de apps no Claude de uma vez.

Supabase

O arquivo de planilhas de um sistema. Para quando for construir.

GitHub

O Drive das páginas e dos códigos. Serve para publicar.
