Antes de tudo

Plugin é uma peça que você encaixa no Claude.

Ele vem com instruções prontas para um tipo de tarefa. Depois de instalado, você não precisa chamar: o Claude usa sozinho quando a tarefa aparece.

A Anthropic publicou várias dessas peças, e elas não custam nada além do que você já paga pelo Claude. O passo a passo é o mesmo para qualquer uma, então aprenda uma vez e instale quantas quiser.

O passo a passo

Instalar leva quatro cliques

É assim no aplicativo do Claude no computador, que é onde a maioria usa.

1
Abra a aba Code no aplicativo do Claude

É a aba onde o Claude trabalha nos seus arquivos. Se você só usa o Claude pelo chat, é essa que você ainda não abriu.

2
Clique no sinal de mais, do lado da caixa de escrever

No menu que abre, escolha Adicionar plugins. Se aparecer Plugins, clique nele e depois em Procurar plugins.

3
Escolha o que você quer na lista e clique

Antes de confirmar, leia o que ele diz que vai instalar. Plugin é código de outra pessoa rodando no seu Claude, então instale só o que você reconhece.

4
Escolha onde ele vale

Para você deixa o plugin disponível em todos os seus projetos. É a opção certa quando você está começando.

Para saber se deu certo: digite uma barra na caixa de escrever e procure o nome do plugin na lista que aparece.

A lista

O que vale a pena ligar hoje

Se você preferir digitar em vez de clicar, cada uma tem o comando pronto para copiar. Cole na caixa de escrever da aba Code e dê enter.

1

Documentos de verdade

Faz o Claude entregar arquivo pronto em Word, Excel, PowerPoint e PDF, em vez de texto na tela para você copiar e formatar na mão.

Serve para: Relatório de paciente, proposta para cliente, planilha de controle, apresentação de reunião.

document-skills
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
2

Ensinar uma tarefa uma vez

Monta com você uma skill nova: você explica uma vez como quer que uma tarefa seja feita e o Claude passa a fazer sempre daquele jeito, sem você repetir.

Serve para: Aquela tarefa que você refaz toda semana e sempre corrige do mesmo jeito.

skill-creator
/plugin install skill-creator@claude-plugins-official
3

Os exemplos que a Anthropic publicou

Um pacote de skills de exemplo, de criação e design até comunicação. Serve para você ver como uma skill é por dentro antes de escrever a sua.

Serve para: Quem quer entender o mecanismo, não só usar.

example-skills
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
Uma coisa que ninguém te fala

Leia antes de instalar, sempre

Plugin é código de outra pessoa rodando dentro do seu Claude, com acesso aos seus arquivos. A própria Anthropic avisa que não controla o que vai dentro de cada um.

Antes de confirmar, a tela mostra tudo o que aquele plugin vai acrescentar. Leia. Se tiver coisa que você não entende, não instale. Os três desta página são publicados pela própria Anthropic, e é por isso que eles estão aqui.
